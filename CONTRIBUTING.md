# Contributing to ARES-01

First off, thank you for considering contributing to ARES-01! It's people like you that make open-source hardware and software such a great community.

## How Can I Contribute?

### Reporting Bugs
* Use the **Bug Report** issue template.
* Describe the issue clearly, including steps to reproduce, expected behavior, and actual behavior.
* Include details about your operating system, Node.js version, and ESP32 board specifics if applicable.

### Suggesting Enhancements
* Use the **Feature Request** issue template.
* Provide a clear and detailed explanation of the feature you want and why it would be useful.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure your code follows the existing architecture (Web/Firmware).
3. If you've added code that should be tested, test it thoroughly with the ESP32 hardware if possible.
4. Update the documentation in `README.md` or `ARES_01_Project_Documentation.md` if you are modifying core features.
5. Issue that pull request using the provided PR template!

## Local Setup
Please refer to the `README.md` for instructions on setting up the ESP32-S3 firmware and the React web application locally.
